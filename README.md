# .github

This repository powers the [Space Odditty organization profile](https://github.com/spaceodditty).

The org-page README lives at [`profile/README.md`](profile/README.md). Visual assets are under [`assets/`](assets/).

Design system: Terminal Brutalist v0.1. The day (light) surface uses the aurora variant — Ink ground `#0A0A0A` with an orange→teal spectrum wordmark; the night (dark) surface keeps the mono pairing (Cream `#F1E7D2` on Ink). The full color/token SSOT lives in studio_hq.
